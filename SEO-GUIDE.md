## 🚀 Étapes pour l'indexation Google

### Étape 1 : Soumettre le site à Google Search Console

1. **Accéder à Google Search Console**
   - Aller sur : https://search.google.com/search-console
   - Se connecter avec un compte Google

2. **Ajouter une propriété**
   - Cliquer sur "Ajouter une propriété"
   - Entrer l'URL de votre site (ex: `https://myproperty.com`)
   - Choisir la méthode de vérification :
     - **Recommandé** : Fichier HTML (télécharger le fichier fourni par Google et le placer à la racine)
     - Alternative : Balise HTML (ajouter une meta tag dans `<head>`)
     - Alternative : Google Analytics
     - Alternative : Google Tag Manager

3. **Vérifier la propriété**
   - Suivre les instructions de Google
   - Une fois vérifié, vous aurez accès aux outils

### Étape 2 : Soumettre le Sitemap

1. **Dans Google Search Console**
   - Aller dans "Sitemaps" (menu de gauche)
   - Entrer : `sitemap.xml`
   - Cliquer sur "Envoyer"

2. **Vérifier l'indexation**
   - Aller dans "Couverture" pour voir les pages indexées
   - Utiliser "Inspection d'URL" pour vérifier une page spécifique

### Étape 3 : Demander l'indexation

1. **Pour chaque page importante**
   - Utiliser l'outil "Inspection d'URL"
   - Entrer l'URL de la page
   - Cliquer sur "Demander l'indexation"

## ⚠️ Notes importantes

1. **URLs à mettre à jour** : N'oubliez pas de remplacer `https://myproperty.com` par votre vraie URL dans tous les fichiers.

3. **Sitemap dynamique** : Si vous ajoutez souvent de nouvelles villas, pensez à générer un sitemap dynamique.

4. **Mises à jour régulières** : Mettez à jour régulièrement le `lastmod` dans `sitemap.xml`.

5. **Contenu unique** : Assurez-vous que chaque villa a une description unique et détaillée.
